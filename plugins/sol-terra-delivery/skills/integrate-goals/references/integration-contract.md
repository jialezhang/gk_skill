# Integration Contract

## Source identity

Pin the approved base commit and every Goal's remote branch and commit. Confirm all Goals share the intended repository and plan revision. A local directory name or branch label is not sufficient identity evidence.

## Conflict ownership

Terra may resolve mechanical and local implementation conflicts that preserve approved contracts. Sol is reserved for evidence that invalidates the plan, architecture, or high-risk security boundary. Product outcome changes return to the user.

## Verification layers

After each dependency wave, run the affected integration boundaries. On the final clean commit run the full approved checks and exact-target journeys. A Goal-level pass cannot substitute for integrated evidence.

## Program evidence

The handoff maps every Goal to session, worktree, branch, clean commit, checkpoint reports, routing log, verification, and integration result. Aggregate model/stage token usage only from runtime telemetry; label gaps as unavailable.
